# E-commerce Sales Dashboard
## Overview
An interactive sales dashboard built in Microsoft Excel to analyze e-commerce performance across regions, categories, and products.
## Dataset

- Source: Kaggle
- Data includes sales, profit, product categories, and regional performance

## Tools Used

- Microsoft Excel
- Pivot Tables
- Slicers
- Charts & Data Visualization

## Key Insights

- Total Profit: ₹18.44 Lakhs
- Total Sales: ₹1.66 Crore
- Top Region: West
- Top Category: Electronics
- Top Product: Camera

## Skills Demonstrated

- Data cleaning and analysis
- Dashboard design
- Business insight generation
